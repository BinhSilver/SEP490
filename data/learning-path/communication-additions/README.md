# Nội dung giao tiếp bổ sung (05/11)

Phần thêm mới cho lộ trình giao tiếp (đợt 2), soạn theo chuẩn mỗi chủ đề ≥ 25 từ, ≥ 8 mẫu câu, ≥ 3 hội thoại.

- `TRAVEL.json`, `DAILY_LIFE.json`, `BA.json`: chỉ chứa phần thêm vào các chủ đề đã có (cùng khuôn với `../communication/<GOAL>.json`).
- `WORK.json`: mục tiêu mới "Tiếng Nhật công việc" (Văn phòng, Sản xuất, Dịch vụ; IT/BrSE nằm trong BA).

Các file `../communication/*.json` do `tools/learning-path-source/build_learning_path_source.mjs` sinh ra từ
`data/learning-owned/learning-content.json`, nên không sửa tay. Khi làm lộ trình giao tiếp, gộp các file ở đây vào nguồn đó.
